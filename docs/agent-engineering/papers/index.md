## 纳入规则

- 只纳入已有中文简介、方法说明或实验解读的论文。
- 只有标题或 URL、尚未完成简介的条目暂不进入本板块。
- 详细内容优先复用已有专题文件；后续可在不改变索引结构的情况下拆成单篇文件。
