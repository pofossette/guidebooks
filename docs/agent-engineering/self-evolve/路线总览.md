# Agent 自进化路线总览

配套细读版见：[论文综述](./论文综述.md)。新补的一篇单篇笔记见：[MUSE-Autoskill](./MUSE-Autoskill.md)。

下面用 `mermaid` 流程图重新梳理三种“自我进化”路线。

## 1. SkillX：把经验沉淀成技能库

```mermaid
flowchart TD
    A[任务执行与轨迹生成] --> B[收集成功轨迹]
    B --> C[多层技能抽取]
    C --> C1[规划技能]
    C --> C2[功能技能]
    C --> C3[原子技能]
    C1 --> D[写入技能知识库]
    C2 --> D
    C3 --> D
    D --> E[基于执行反馈精炼]
    E --> F[探索低覆盖工具与高失败模式]
    F --> G[验证新技能]
    G --> H[更新技能知识库]
    H --> I[下一轮任务复用]
```

- 进化对象：技能知识库（Skill Knowledge Base，SkillKB）
- 核心机制：轨迹抽取、多层技能表示、反馈精炼、主动扩展
- 一句话：SkillX 让 Agent 的经验沉淀为一个越来越强、可迁移的技能库。

## 2. MUSE-Autoskill：把技能做成长生命周期资产

```mermaid
flowchart TD
    A[任务运行中发现技能缺口] --> B[skill_create 按需生成技能包]
    B --> C[生成 SKILL.md / scripts / tests]
    C --> D[运行测试做准入验证]
    D -->|失败| E[根据失败轨迹修补 skill]
    E --> D
    D -->|通过| F[注册到 Skill Bank]
    F --> G[绑定 .memory.md 记录经验]
    G --> H[后续任务检索并复用]
    H --> I[根据运行效果 merge / update / forget]
    I --> F
```

- 进化对象：单个 skill 的完整生命周期
- 核心机制：运行时创建、技能级记忆、测试准入、失败修补、技能治理
- 一句话：MUSE-Autoskill 让 skill 不再是一段静态经验，而是可持续运维的工程资产。

## 3. Strategy Genes：把经验压缩成策略基因

```mermaid
flowchart TD
    A[历史轨迹与过程化技能] --> B[压缩为策略基因]
    B --> B1[适用信号]
    B --> B2[策略摘要]
    B --> B3[执行策略]
    B --> B4[避免事项]
    B --> B5[验证方式]
    B1 --> C[测试时注入模型]
    B2 --> C
    B3 --> C
    B4 --> C
    B5 --> C
    C --> D[执行任务并接收反馈]
    D --> E[评估 Gene 效果]
    E --> E1[保留有效策略]
    E --> E2[写入失败模式]
    E --> E3[删除冗余信息]
    E --> E4[改写不稳定策略]
    E1 --> F[更新策略基因]
    E2 --> F
    E3 --> F
    E4 --> F
    F --> G[下一轮推理继续注入]
```

- 进化对象：策略基因（Strategy Gene）
- 核心机制：经验压缩、测试时控制、失败蒸馏、持续修订
- 一句话：Strategy Genes 让经验从“长文档”进化成“短小、可编辑的控制信号”。

## 4. Evolver / GEP：把自进化做成工程流水线

```mermaid
flowchart TD
    A[项目上下文输入] --> B[选择相关资产]
    B --> C[生成修改方案]
    C --> D[运行验证]
    D -->|失败| E[回滚或重新生成]
    E --> B
    D -->|成功| F[固化进化资产]
    F --> F1[基因资产]
    F --> F2[胶囊资产]
    F --> F3[事件日志]
    F1 --> G[记录演化事件]
    F2 --> G
    F3 --> G
    G --> H[共享复用]
    H --> B
```

- 进化对象：基因、胶囊、事件日志
- 核心机制：资产选择、修改生成、验证固化、审计复用
- 一句话：Evolver 把自我进化从“写经验”推进成“可验证、可回滚、可审计”的工程系统。

## 6. 最简理解

### 6.1 SkillX

```mermaid
flowchart LR
    A1[经验] --> B1[技能]
    B1 --> C1[技能库]
    C1 --> D1[反馈精炼]
    D1 --> E1[更强技能库]
```

### 6.2 MUSE-Autoskill

```mermaid
flowchart LR
    A2[成功轨迹] --> B2[Skill 包]
    B2 --> C2[测试与修补]
    C2 --> D2[记忆与治理]
    D2 --> E2[长期技能资产]
```

### 6.3 Strategy Genes

```mermaid
flowchart LR
    A3[经验] --> B3[Gene]
    B3 --> C3[测试时控制]
    C3 --> D3[反馈修订]
    D3 --> E3[更强 Gene]
```

### 6.4 Evolver / GEP

```mermaid
flowchart LR
    A4[项目状态] --> B4[Gene / Capsule]
    B4 --> C4[修改]
    C4 --> D4[验证]
    D4 --> E4[固化资产]
```

## 7. 一句话总结

- SkillX：进化的是“技能库”。
- MUSE-Autoskill：进化的是“技能的生命周期”。
- Strategy Genes：进化的是“经验表示”。
- Evolver：进化的是“工程资产和演化流程”。
