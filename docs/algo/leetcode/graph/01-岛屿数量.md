# 岛屿数量

> 标签：图、DFS、Flood Fill | 语言：TypeScript | 面试记录：1次，百度二面

## 1. 题目理解

给定一个由 `'1'` 和 `'0'` 组成的二维网格，统计网格中岛屿的数量。岛屿由上下左右相连的陆地组成，所以重点是找到一块陆地后，把它整片都标记掉，避免重复计数。

## 2. 解题思路

遍历整个网格，每遇到一个 `'1'`，答案加一，然后从这个位置开始做 DFS，把所有连通的陆地都访问掉。访问过的格子直接原地从 `'1'` 改成 `'0'`，这样就相当于完成了 visited 标记，不需要额外的访问数组。

## 3. TypeScript 实现

```typescript
function numIslands(grid: string[][]): number {
  if (grid.length === 0) return 0;

  const rows = grid.length;
  const cols = grid[0].length;
  let count = 0;

  function dfs(row: number, col: number): void {
    if (row < 0 || row >= rows || col < 0 || col >= cols || grid[row][col] !== "1") {
      return;
    }

    grid[row][col] = "0";

    dfs(row + 1, col);
    dfs(row - 1, col);
    dfs(row, col + 1);
    dfs(row, col - 1);
  }

  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < cols; col++) {
      if (grid[row][col] !== "1") continue;

      count++;
      dfs(row, col);
    }
  }

  return count;
}
```

## 4. 复杂度分析

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(m * n)`，最坏情况下递归栈会走满整张网格

## 5. 易错点

- 访问过的陆地要立刻从 `'1'` 改成 `'0'`，否则会被重复统计
- 题目只允许上下左右四个方向连通，不能把对角线算进去
- 空网格要先处理，避免直接访问 `grid[0]`

## 6. 面试怎么说

这题本质是网格上的连通块计数。每扫到一个还没访问过的 `'1'`，就说明发现了一座新岛屿，然后用 DFS 把整片陆地淹掉，后面再扫到它时就不会重复计数。
