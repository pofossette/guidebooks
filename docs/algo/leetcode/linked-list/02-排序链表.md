# 排序链表

> 标签：链表、归并排序、快慢指针 | 语言：TypeScript | 面试记录：2次，快手，美团一面

## 1. 题目理解

给定一个链表，要求按升序排序并返回排序后的头节点。因为链表不支持随机访问，像数组那样直接快排不合适，更适合用归并排序。

## 2. 解题思路

先用快慢指针找中点，把链表断成左右两半。递归分别排序后，再把两个有序链表合并。快指针一次走两步、慢指针一次走一步，慢指针停下的位置就是中间附近，适合做分治切分。

## 3. TypeScript 实现

```typescript
class ListNode {
  val: number;
  next: ListNode | null;

  constructor(val = 0, next: ListNode | null = null) {
    this.val = val;
    this.next = next;
  }
}

function sortList(head: ListNode | null): ListNode | null {
  if (!head || !head.next) {
    return head;
  }

  let slow: ListNode | null = head;
  let fast: ListNode | null = head;
  let prev: ListNode | null = null;

  while (fast && fast.next) {
    prev = slow;
    slow = slow!.next;
    fast = fast.next.next;
  }

  prev!.next = null;

  const left = sortList(head);
  const right = sortList(slow);

  return merge(left, right);
}

function merge(left: ListNode | null, right: ListNode | null): ListNode | null {
  const dummy = new ListNode();
  let tail = dummy;

  while (left && right) {
    if (left.val <= right.val) {
      tail.next = left;
      left = left.next;
    } else {
      tail.next = right;
      right = right.next;
    }
    tail = tail.next;
  }

  tail.next = left ?? right;
  return dummy.next;
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(log n)`，主要来自递归栈

## 5. 易错点

- 快慢指针切分后要把 `prev.next = null` 断开，否则会无限递归
- 链表归并时要返回 `dummy.next`，不要返回虚拟头节点本身
- 递归终止条件是空节点或单节点

## 6. 面试怎么说

链表排序最稳妥的是归并排序，因为它天然适合顺序访问结构。先用快慢指针把链表二分，再递归排序左右两边，最后线性合并两个有序链表，整体复杂度是 `O(n log n)`。
