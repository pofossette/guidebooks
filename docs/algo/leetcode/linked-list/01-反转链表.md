# 反转链表

> 标签：链表、双指针、迭代 | 语言：TypeScript | 面试记录：常见高频题

## 1. 题目理解

给定一个单链表头节点，需要把链表原地反转并返回新的头节点。重点不是新建数组再回填，而是把指针方向逐个翻过来。

## 2. 解题思路

用三个指针顺序推进：`prev` 记录已经反转好的前半段，`curr` 指向当前节点，`next` 暂存后继节点，避免断链。每次把 `curr.next` 指向 `prev`，然后整体向前移动一格。

## 3. TypeScript 实现

```typescript
class ListNode {
  val: number;
  next: ListNode | null;

  constructor(val = 0, next: ListNode | null = null) {
    this.val = val;
    this.next = next;
  }
}

function reverseList(head: ListNode | null): ListNode | null {
  let prev: ListNode | null = null;
  let curr: ListNode | null = head;

  while (curr) {
    const next: ListNode | null = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
  }

  return prev;
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 5. 易错点

- 修改 `curr.next` 之前必须先保存 `next`，否则后续链表会丢失
- 循环结束后返回的是 `prev`，不是原始 `head`
- 空链表和单节点链表都要直接兼容

## 6. 面试怎么说

这题的核心是指针原地翻转，不需要额外容器。维护 `prev`、`curr`、`next` 三个变量，保证每次反转一个节点后还能继续往后遍历，最后 `prev` 就是新的头节点。
