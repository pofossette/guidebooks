# 有效的括号

> 标签：栈、字符串、匹配 | 语言：TypeScript | 面试记录：1次，腾讯一面

## 1. 题目理解

给定一个只包含括号字符的字符串，判断它是否是合法括号序列。合法的关键在于顺序正确且每个右括号都能匹配最近的左括号。

## 2. 解题思路

用栈保存还没被匹配的左括号，再用一个映射表把右括号映射回对应的左括号。遍历字符串时，遇到左括号就入栈，遇到右括号就检查栈顶是否和映射表里的左括号一致；另外如果字符串长度是奇数，可以直接提前返回 `false`。

## 3. TypeScript 实现

```typescript
function isValid(s: string): boolean {
  if (s.length % 2 === 1) return false;

  const stack: string[] = [];
  const pairs = new Map<string, string>([
    [")", "("],
    ["]", "["],
    ["}", "{"],
  ]);

  for (const char of s) {
    if (!pairs.has(char)) {
      stack.push(char);
      continue;
    }

    if (stack.pop() !== pairs.get(char)) {
      return false;
    }
  }

  return stack.length === 0;
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 5. 易错点

- 字符串长度为奇数时不可能完全配对，可以直接提前失败
- 匹配时要比较栈顶和当前右括号对应的左括号，而不是只看字符是否出现过
- 遍历结束后还要检查栈是否为空，否则说明还有未匹配的左括号

## 6. 面试怎么说

这题适合用栈模拟括号匹配过程。左括号入栈，右括号就和栈顶做匹配，永远只关心最近那个还没闭合的左括号，所以栈是最自然的数据结构。
