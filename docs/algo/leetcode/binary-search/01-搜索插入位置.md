# 搜索插入位置

> 标签：二分查找、有序数组、边界查找 | 语言：TypeScript | 面试记录：常见高频题

## 1. 题目理解

给定一个升序数组和目标值，要求返回目标值在数组中的索引；如果不存在，则返回它按顺序应该插入的位置。重点不是找到任意一个相等位置，而是找到第一个大于等于 `target` 的位置。

## 2. 解题思路

用二分查找收缩区间，维护答案始终落在 `[left, right]` 范围内。如果 `nums[mid] < target`，说明插入位置一定在右边；否则说明 `mid` 可能就是答案，继续去左边收缩。循环结束后，`left` 停在第一个 `>= target` 的位置，如果所有元素都比目标小，它就自然落在数组末尾，这正是插入点。

## 3. TypeScript 实现

```typescript
function searchInsert(nums: number[], target: number): number {
  let left = 0;
  let right = nums.length - 1;

  while (left <= right) {
    const mid = Math.floor((left + right) / 2);

    if (nums[mid] < target) {
      left = mid + 1;
    } else {
      right = mid - 1;
    }
  }

  return left;
}
```

## 4. 复杂度分析

- 时间复杂度：`O(log n)`
- 空间复杂度：`O(1)`

## 5. 易错点

- 这题要找的是第一个 `>= target` 的位置，不是只要找到相等值就立刻返回
- 循环结束后返回 `left`，因为它最终停在合法插入点上
- 当目标值比所有元素都大时，`left` 会走到 `nums.length`，这是正确答案

## 6. 面试怎么说

这是一个标准左边界二分。只要当前值小于目标，就把左边界推进；否则收缩右边界，继续找更靠左的位置。最后返回的 `left` 就是目标应该出现的第一个位置，也就是插入位置。
