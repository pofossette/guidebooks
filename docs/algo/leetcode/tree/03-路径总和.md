# 路径总和

> 标签：二叉树、深度优先搜索、递归 | 语言：TypeScript | 面试记录：常见高频题

## 1. 题目理解

给定一棵二叉树和一个目标和，判断是否存在一条从根节点到叶子节点的路径，使路径上所有节点值之和等于目标值。这里必须是从根到叶子的完整路径，不能停在中间节点。

## 2. 解题思路

使用 DFS 递归。每到一个节点，就把 `targetSum` 减去当前节点值，继续递归左右子树；如果走到叶子节点，只有“当前值恰好等于剩余目标和”时才返回 `true`。

## 3. TypeScript 实现

```typescript
class TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;

  constructor(val = 0, left: TreeNode | null = null, right: TreeNode | null = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

function hasPathSum(root: TreeNode | null, targetSum: number): boolean {
  if (!root) {
    return false;
  }

  if (!root.left && !root.right) {
    return root.val === targetSum;
  }

  const remaining = targetSum - root.val;

  return hasPathSum(root.left, remaining) || hasPathSum(root.right, remaining);
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`，`h` 是树高

## 5. 易错点

- 必须判断到叶子节点才可以比较是否命中目标和
- 空树返回 `false`
- 递归传递的是“剩余和”，不是每次重新从根计算路径和

## 6. 面试怎么说

这题适合直接做 DFS。把问题转成“子树里是否存在剩余和为 `targetSum - root.val` 的根到叶子路径”，递归到叶子节点时做精确判断，逻辑最直接。
