# 二叉树中序遍历

> 标签：二叉树、栈、迭代遍历 | 语言：TypeScript | 面试记录：1次，百度一面

## 1. 题目理解

给定一棵二叉树，按中序遍历顺序返回节点值，也就是左子树、根节点、右子树。这里主解法用非递归写法，更贴近面试里对栈模拟过程的考察。

## 2. 解题思路

维护一个栈和当前指针。一路把左子节点压栈，直到为空；然后弹出栈顶节点加入结果，再转向它的右子树，重复这个过程。

## 3. TypeScript 实现

```typescript
class TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;

  constructor(val = 0, left: TreeNode | null = null, right: TreeNode | null = null) {
    this.val = val;
    this.left = left;
    this.right = right;
  }
}

function inorderTraversal(root: TreeNode | null): number[] {
  const result: number[] = [];
  const stack: TreeNode[] = [];
  let current: TreeNode | null = root;

  while (current || stack.length > 0) {
    while (current) {
      stack.push(current);
      current = current.left;
    }

    current = stack.pop()!;
    result.push(current.val);
    current = current.right;
  }

  return result;
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，最坏情况下栈会退化到链表高度

## 5. 易错点

- 不能只在根节点层面循环，外层条件必须是 `current || stack.length > 0`
- 弹出栈顶后先记录节点值，再去右子树
- 空树要返回空数组

## 6. 面试怎么说

非递归中序遍历本质是在手动模拟调用栈。先不断向左压栈，走到尽头后弹出访问，再切到右子树继续，整个顺序刚好就是左根右。
