# 字母异位词分组

> 标签：数组、哈希表、字符串排序 | 语言：TypeScript | 面试记录：1次，xhs一面

## 1. 题目理解

给定一组字符串，需要把由相同字母重排得到的字符串放进同一组。关键是找到一个稳定的分组标识。

## 2. 解题思路

把每个字符串排序后得到规范化结果，并把这个排序后的字符串作为哈希 key。遍历原数组时，把原字符串追加到对应 key 的数组里，最后返回所有分组。

## 3. TypeScript 实现

```typescript
function groupAnagrams(strs: string[]): string[][] {
  const groups = new Map<string, string[]>();

  for (const str of strs) {
    const key = str.split("").sort().join("");
    const bucket = groups.get(key) ?? [];
    bucket.push(str);
    groups.set(key, bucket);
  }

  return Array.from(groups.values());
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n * k log k)`，其中 `k` 是字符串平均长度
- 空间复杂度：`O(n * k)`，主要来自哈希表和结果存储

## 5. 易错点

- key 不能直接用原字符串，否则无法把异位词归到一组
- 排序后的 key 要重新拼回字符串，不能保留成字符数组
- 返回值是二维数组，不要求组内顺序固定

## 6. 面试怎么说

这题本质是把“是否互为异位词”转成“规范化后是否相等”。最稳定的做法是把每个字符串排序，用排序结果做哈希 key，这样实现简单，复杂度也容易说明。
