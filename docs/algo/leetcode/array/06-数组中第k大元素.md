# 数组中第 k 大元素

> 标签：数组、快速选择、分治 | 语言：TypeScript | 面试记录：1次，腾讯一面

## 1. 题目理解

要求找出数组中第 `k` 大的元素，不是排序后去重的第 `k` 个不同值，而是按整体排序后的第 `k` 个位置。重点是比完整排序更高效地定位目标。

## 2. 解题思路

主解法选择 quickselect。把问题转成找升序排列后的下标 `nums.length - k`，每次 partition 后判断基准点是否正好落在目标位置：如果是就直接返回，否则只递归一侧，避免完整排序。面试里也可以补充最小堆做法作为备选方案。

## 3. TypeScript 实现

```typescript
function findKthLargest(nums: number[], k: number): number {
  const target = nums.length - k;

  function partition(left: number, right: number): number {
    const pivot = nums[right];
    let storeIndex = left;

    for (let i = left; i < right; i++) {
      if (nums[i] <= pivot) {
        [nums[i], nums[storeIndex]] = [nums[storeIndex], nums[i]];
        storeIndex++;
      }
    }

    [nums[storeIndex], nums[right]] = [nums[right], nums[storeIndex]];
    return storeIndex;
  }

  let left = 0;
  let right = nums.length - 1;

  while (left <= right) {
    const pivotIndex = partition(left, right);

    if (pivotIndex === target) {
      return nums[pivotIndex];
    }

    if (pivotIndex < target) {
      left = pivotIndex + 1;
    } else {
      right = pivotIndex - 1;
    }
  }

  return -1;
}
```

## 4. 复杂度分析

- 平均时间复杂度：`O(n)`
- 平均空间复杂度：`O(1)`，这里使用迭代版 quickselect

## 5. 易错点

- 目标下标是 `nums.length - k`，不是 `k - 1`
- partition 比较方向要和目标下标定义保持一致
- quickselect 平均是 `O(n)`，但最坏情况下会退化到 `O(n^2)`

## 6. 面试怎么说

我会先说 quickselect，因为它比完整排序更贴近这题本质，只关心目标位置而不是全部有序。目标下标是 `nums.length - k`。如果面试官追问稳定备选方案，可以补充维护大小为 `k` 的最小堆，时间复杂度是 `O(n log k)`。
