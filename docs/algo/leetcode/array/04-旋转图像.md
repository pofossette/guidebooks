# 旋转图像

> 标签：数组、矩阵、原地修改 | 语言：TypeScript | 面试记录：1次，美团一面

## 1. 题目理解

给定一个 `n x n` 的正方形矩阵，需要把图像顺时针旋转 90 度，而且要原地完成，不能再创建一个新的矩阵承接结果。

## 2. 解题思路

顺时针旋转 90 度可以拆成两步：先沿主对角线转置，再把每一行左右翻转。转置会把行列互换，行内翻转再把位置调整到顺时针旋转后的最终状态。整个过程只是在原矩阵上交换元素。

## 3. TypeScript 实现

```typescript
function rotate(matrix: number[][]): void {
  const n = matrix.length;

  for (let row = 0; row < n; row++) {
    for (let col = row + 1; col < n; col++) {
      [matrix[row][col], matrix[col][row]] = [matrix[col][row], matrix[row][col]];
    }
  }

  for (const row of matrix) {
    let left = 0;
    let right = n - 1;

    while (left < right) {
      [row[left], row[right]] = [row[right], row[left]];
      left++;
      right--;
    }
  }
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(1)`，因为只做原地交换，没有使用和矩阵规模相关的额外存储

## 5. 易错点

- 这题是正方形矩阵原地旋转，不能按普通新矩阵映射去写主解法
- 转置时内层循环要从 `col = row + 1` 开始，避免重复交换
- 转置之后还要对每一行做翻转，少一步都会导致结果不对

## 6. 面试怎么说

如果要求原地旋转，我会把它拆成“转置 + 每行翻转”。这两个操作都只是在矩阵内部交换元素，所以额外空间是 `O(1)`，也比直接背坐标变换更容易讲清楚。
