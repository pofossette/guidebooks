# 合并区间

> 标签：数组、排序、区间问题 | 语言：TypeScript | 面试记录：1次，Shopee一面

## 1. 题目理解

给定若干区间，要求把所有有重叠的部分合并起来，最后输出互不重叠的区间集合。输入顺序不重要，关键是正确处理相交和包含关系。

## 2. 解题思路

先按区间左端点排序，这样重叠区间一定会相邻出现。遍历时维护一个当前区间：如果下一个区间和它相交，就更新右边界；如果不相交，就把当前区间加入答案并切换到新区间。空数组直接返回，完全嵌套的区间会自然被右边界更新逻辑覆盖。

## 3. TypeScript 实现

```typescript
function merge(intervals: number[][]): number[][] {
  if (intervals.length === 0) return [];

  intervals.sort((a, b) => a[0] - b[0]);

  const result: number[][] = [];
  let current = [...intervals[0]];

  for (let i = 1; i < intervals.length; i++) {
    const [start, end] = intervals[i];

    if (start <= current[1]) {
      current[1] = Math.max(current[1], end);
    } else {
      result.push(current);
      current = [start, end];
    }
  }

  result.push(current);
  return result;
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n log n)`，瓶颈在排序
- 空间复杂度：`O(n)`，主要来自结果数组

## 5. 易错点

- 输入可能是空数组，需要先处理
- 排序必须按左端点进行，否则无法线性合并
- 完全嵌套区间也属于重叠，更新右边界时要取 `Math.max`

## 6. 面试怎么说

区间题一般先想排序，把无序输入变成可线性扫描的问题。这里按左端点排序后，只要维护一个当前区间，遇到重叠就扩展，遇到断开就落盘，思路很稳定。
