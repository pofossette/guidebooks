# 轮转数组

> 标签：数组、原地修改、双指针 | 语言：TypeScript | 面试记录：1次，携程一面

## 1. 题目理解

把数组中的元素整体向右轮转 `k` 步，而且题目通常要求尽量原地完成，而不是额外开一个同等大小的新数组。

## 2. 解题思路

主解法用三次翻转：先翻转整个数组，再翻转前 `k` 个元素，最后翻转剩余部分。这样等价于把尾部长度为 `k` 的片段移动到前面，同时保留各自内部顺序。开始前先做 `k %= nums.length`，避免 `k` 大于数组长度。

## 3. TypeScript 实现

```typescript
function reverse(nums: number[], left: number, right: number): void {
  while (left < right) {
    [nums[left], nums[right]] = [nums[right], nums[left]];
    left++;
    right--;
  }
}

function rotate(nums: number[], k: number): void {
  if (nums.length === 0) return;

  k %= nums.length;
  if (k === 0) return;

  reverse(nums, 0, nums.length - 1);
  reverse(nums, 0, k - 1);
  reverse(nums, k, nums.length - 1);
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 5. 易错点

- 数组为空时要先返回，否则 `k %= nums.length` 会除以 0
- `k` 可能大于数组长度，必须先做 `k %= nums.length`
- 三次翻转的区间边界很容易写错，尤其是第二段和第三段

## 6. 面试怎么说

这题我会优先给原地三次翻转，因为它比额外数组更符合进阶要求。先整体翻转，再分别翻转前半段和后半段，空间复杂度能做到 `O(1)`。
