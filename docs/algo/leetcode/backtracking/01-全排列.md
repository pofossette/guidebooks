# 全排列

> 标签：回溯、DFS、状态恢复 | 语言：TypeScript | 面试记录：常见高频题

## 1. 题目理解

给定一个不含重复数字的数组，返回它的所有排列结果。重点不是把结果硬枚举出来，而是理解每一层递归在决定当前位置放哪个数。

## 2. 解题思路

用 DFS 按位置逐层构造排列，`path` 记录当前已经选好的数字，`used` 数组记录每个下标是否已经被使用。每次选择一个还没用过的数字加入 `path`，递归结束后再通过 `pop` 和重置 `used[i]` 完成状态恢复，继续尝试下一种选择。

## 3. TypeScript 实现

```typescript
function permute(nums: number[]): number[][] {
  const result: number[][] = [];
  const path: number[] = [];
  const used: boolean[] = new Array(nums.length).fill(false);

  function dfs(): void {
    if (path.length === nums.length) {
      result.push([...path]);
      return;
    }

    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;

      used[i] = true;
      path.push(nums[i]);
      dfs();
      path.pop();
      used[i] = false;
    }
  }

  dfs();
  return result;
}
```

## 4. 复杂度分析

- 时间复杂度：`O(n * n!)`
- 空间复杂度：`O(n)`，不计返回结果

## 5. 易错点

- 到达叶子节点时要用 `result.push([...path])` 拷贝当前路径，不能直接推入原数组引用
- 回溯返回后要同时做两步状态恢复：`path.pop()` 和 `used[i] = false`
- `used` 记录的是下标是否被使用，不是数字值本身

## 6. 面试怎么说

这题本质是枚举每个位置放哪个数字。DFS 负责一层层往下试，`used` 保证同一个数字不会在同一条路径里重复使用，递归回来后通过 `pop` 和重置标记完成回溯，这就是典型的试错加状态恢复。
