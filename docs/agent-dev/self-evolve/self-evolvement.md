```text

│ 目标：把 Agent 经验沉淀成可迁移 SkillKB        │

        ▼
多层技能抽取

        ▼

形成可复用技能知识库
        │
        ▼

        │
        ▼
探索式扩展
针对低覆盖工具、高失败行为生成新任务
        │
        ▼
验证新技能是否有效
        │
        └───────────────┐
                        ▼
                 更新 SkillKB
                        │

核心机制：轨迹 → 技能抽取 → 技能库 → 反馈精炼 → 探索扩展

```

## 总体对比流程

```text
              ┌──────────────────────┐
              │ Agent 执行任务产生经验 │
              └──────────┬───────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
        ▼                ▼                ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   SkillX     │  │ Strategy Gene│  │   Evolver    │
├──────────────┤  ├──────────────┤  ├──────────────┤
│ 抽取多层技能  │  │ 压缩经验表示  │  │ 选择工程资产  │
│ 构建 SkillKB │  │ 形成 Gene     │  │ 生成修改方案  │
│ 反馈精炼技能  │  │ 反馈修订 Gene │  │ 验证并固化    │
└──────┬───────┘  └──────┬───────┘  └──────┬───────┘
       │                 │                 │
       ▼                 ▼                 ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ 更强技能库    │  │ 更优策略基因  │  │ 可审计进化资产│
└──────────────┘  └──────────────┘  └──────────────┘
       │                 │                 │
       └─────────────────┼─────────────────┘
                         ▼
              ┌──────────────────────┐
              │ 下一轮任务表现提升     │
              └──────────────────────┘
```

## 最简理解

```text
SkillX
经验 ──► 技能 ──► 技能库 ──► 反馈精炼 ──► 更强技能库

Strategy Genes
经验 ──► Gene ──► 测试时控制 ──► 反馈修订 ──► 更强 Gene

Evolver
项目状态 ──► Gene/Capsule ──► 修改 ──► 验证 ──► 固化资产
```

**一句话总结：**

```text
SkillX        ：进化的是“技能库”
Strategy Genes：进化的是“经验表示”
Evolver       ：进化的是“工程资产 + 演化流程”
```
