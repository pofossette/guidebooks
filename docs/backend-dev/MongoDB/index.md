# MongoDB

这一组文档面向已经有一点后端基础、但希望快速建立 NoSQL 尤其是 MongoDB 知识体系的开发者。

写法上参考 `JavaGuide` 的知识地图组织方式，同时延续当前仓库里 PostgreSQL、Redis 专题的“通俗串讲”风格。

目标不是替代官方文档，而是先帮你把 MongoDB 的主线建立起来：

**MongoDB 是什么 -> 适合解决什么问题 -> 数据模型怎么设计 -> 查询和索引怎么用 -> 副本集、分片和性能怎么理解**
