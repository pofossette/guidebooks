# 06. 副本集、分片与高可用扩展

当 MongoDB 不再只是本地开发玩具，而是进入线上系统后，你就要开始理解它的高可用和扩展方式。

## 一、副本集是在解决什么问题

副本集最主要解决两件事：

- 数据副本
- 高可用切换

也就是说，别让数据库只有单点。

## 二、分片是在解决什么问题

分片主要是为了解决：

- 单机容量不够
- 单机吞吐受限

你可以把它理解成：

**把数据和流量拆到多台机器上。**

## 三、什么时候不用急着上分片

很多系统还没把索引、查询、建模做对，就急着分片，这通常太早了。

分片不是第一选择，通常是：

- 数据量真的很大
- 写入和查询压力真的上来了
- 单机和简单扩容已经不够

## 四、MongoDB 线上最值得先建立的意识

1. 单点风险
2. 备份和恢复
3. 索引和查询成本
4. 文档大小和分布

## 这篇最重要的结论

MongoDB 的副本集解决高可用，分片解决更大规模扩展。但大多数项目在走到这一步之前，先把建模、查询和索引做好，收益往往更大。
