# 高性能

这一组文档参考 `JavaGuide` 的高性能栏目组织方式来写，目标是用更通俗的方式说明：

**系统为什么会慢，慢在哪，以及应该优先怎么优化。**

很多人学高性能时容易走偏：

- 只盯着数据库
- 只盯着代码微优化
- 一上来就讨论分库分表

其实高性能的主线更适合这样理解：

**网络入口 -> 应用处理 -> 数据读写 -> 异步削峰 -> 容量评估**

## 基本思路

高性能可以先按 4 层来看：

### 1. 入口层

- CDN
- 负载均衡
- 网关

### 2. 应用层

- 限流
- 异步化
- 线程池 / 连接池
- 批处理

### 3. 数据层

- 索引
- SQL 优化
- 读写分离
- 分库分表
- 冷热分离

### 4. 削峰层

- 消息队列
- 延迟处理
- 重试和补偿

如果把这 4 层主线抓住，大部分性能优化动作都能找到落点。

## 推荐顺序

1. 先看高性能基础，建立整体优化顺序。
2. 再看入口层和应用层，理解请求为什么在前半段变慢。
3. 然后看数据层和削峰层，理解数据库压力和高峰流量怎么处理。
4. 最后看压测、性能测试和容量规划，把优化变成可测量结果。
