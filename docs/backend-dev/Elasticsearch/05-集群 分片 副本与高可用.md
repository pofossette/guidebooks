# 05. 集群、分片、副本与高可用

当 ES 真正进入线上之后，你就不能只把它当单机搜索服务看了。

## 一、分片是在解决什么问题

分片是为了把数据分散到多台节点上：

- 提升容量
- 分担查询压力

## 二、副本是在解决什么问题

副本主要解决：

- 高可用
- 读能力增强

## 三、为什么分片和副本都要谨慎设计

不是越多越好。

因为：

- 管理开销会增加
- 资源消耗会增加
- 查询协调也会更复杂

## 四、学习 ES 集群最先建立什么意识

1. 搜索系统也有单点风险
2. 分片决定扩展方式
3. 副本决定容灾和读取冗余

## 这篇最重要的结论

ES 的高可用和扩展能力，主要建立在分片和副本之上。但这套能力不是白来的，设计不当也会带来性能和运维成本。
