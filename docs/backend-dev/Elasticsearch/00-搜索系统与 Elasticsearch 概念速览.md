# 00. 搜索系统与 Elasticsearch 概念速览

很多人第一次接触 Elasticsearch，都会先问一句：

**为什么数据库明明能查数据，还要额外上一个搜索系统？**

这是个很好的起点。

## 一、搜索系统和数据库有什么区别

数据库更擅长：

- 精确查询
- 事务
- 强结构化数据

搜索系统更擅长：

- 全文检索
- 模糊匹配
- 复杂筛选和排序
- 海量日志或文本分析

也就是说：

**数据库更像“把数据存对”，搜索系统更像“把数据搜快、搜灵活”。**

## 二、Elasticsearch 是什么

Elasticsearch 可以先理解成：

**一个面向搜索和分析场景的分布式文档检索引擎。**

它能处理：

- 文章搜索
- 商品搜索
- 日志检索
- 条件过滤
- 聚合分析

## 三、为什么 Elasticsearch 很常见

因为很多业务在某个阶段都会遇到数据库不顺手的问题：

- 要搜文章标题和正文
- 要做关键词高亮
- 要按相关性排序
- 要在大批日志里查异常

这时传统关系型数据库往往不是最舒服的工具。

## 四、学习 Elasticsearch 的主线

建议按这个顺序：

1. ES 的定位
2. 倒排索引和分词
3. 常见查询方式
4. 映射和索引设计
5. 分片、副本和集群
6. 工程边界和同步方案

## 这篇最重要的结论

Elasticsearch 的价值，不是“又一个数据库”，而是把全文检索、复杂搜索和分析能力做得更强。先理解这个定位，后面很多知识点才不会混。
