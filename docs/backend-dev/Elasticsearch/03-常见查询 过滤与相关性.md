# 03. 常见查询、过滤与相关性

很多人第一次用 ES，会把它理解成“另一种 where 条件”。

这不够。

ES 查询最核心的三个关键词是：

- 查询
- 过滤
- 相关性

## 一、查询和过滤有什么区别

### 查询

更关注匹配程度和相关性得分。

### 过滤

更关注条件是否满足。

比如：

- `status = published`
- `created_at > ...`

这类更像过滤。

## 二、为什么相关性重要

搜索系统不只是“有没有”，还要决定：

**哪个结果更应该排前面。**

这就是相关性排序的意义。

## 三、ES 常见搜索场景

- 关键词搜索
- 分类筛选
- 时间范围筛选
- 标签组合查询
- 搜索词 + 过滤条件一起用

## 这篇最重要的结论

ES 的查询不是简单匹配，而是把文本匹配、条件过滤和相关性排序组合起来理解。
