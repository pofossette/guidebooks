# 04. 映射、索引设计与性能认知

ES 用得顺不顺，很多时候不取决于“会不会查”，而取决于“索引建得对不对”。

## 一、映射是在解决什么问题

映射可以先理解成：

**告诉 Elasticsearch 每个字段应该按什么方式被理解和索引。**

例如：

- 是文本
- 是关键词
- 是数字
- 是时间

## 二、为什么字段类型这么重要

因为不同字段的使用方式完全不同：

- 标题、正文更适合全文搜索
- 状态、标签、ID 更适合精确过滤

如果类型理解错了，查询效果和性能都会受影响。

## 三、ES 里的性能认知先抓什么

1. 字段到底怎么索引
2. 文本字段和精确字段的区别
3. 查询是不是扫了太多数据
4. 聚合和排序是不是很重

## 这篇最重要的结论

ES 的映射设计本质上是在决定“数据以后怎么被搜”。这一步做错，后面查得慢、搜得怪，基本都不奇怪。
