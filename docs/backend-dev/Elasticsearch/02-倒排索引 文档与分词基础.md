# 02. 倒排索引、文档与分词基础

如果学 ES 只记一个底层概念，那就是：

**倒排索引。**

## 一、什么叫倒排索引

你可以先把它粗暴理解成：

**不是从文档找词，而是先记录“词出现在哪些文档里”。**

这让全文检索效率大幅提升。

## 二、为什么分词很重要

因为搜索不是简单字符串比较。

系统要先把文本拆成可搜索的词项，再建立索引。

对中文尤其重要。

## 三、文档在 ES 里是什么

ES 里存储的基本单位也是文档。

你可以把它理解成一条可被搜索和分析的数据记录。

## 四、学习这一块时先建立什么认知

1. 搜索不是简单 SQL `LIKE`
2. 文本字段和精确过滤字段处理方式不同
3. 分词策略会直接影响搜索效果

## 这篇最重要的结论

倒排索引决定了 ES 为什么适合全文搜索，分词决定了它搜出来的结果像不像人预期。
