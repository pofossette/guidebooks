# Elasticsearch

这一组文档面向希望快速建立 Elasticsearch 概念体系的开发者。

写法参考 `JavaGuide` 的知识地图和当前仓库数据库专题的组织方式，目标是帮你先把 ES 放到正确的位置上理解：

**它不是主业务数据库的简单替代品，而是搜索、全文检索、日志分析和复杂检索能力很强的引擎。**
