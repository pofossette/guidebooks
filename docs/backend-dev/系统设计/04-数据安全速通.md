# 04. 数据安全速通

这篇参考 `JavaGuide` 的安全相关写法，结合后端项目最常见的实际问题来讲。目标不是把你变成安全专家，而是先让你知道：

**一个后端系统的数据到底会在哪些地方出问题。**

## 一、先建立一个最基本的安全观念

很多人一提数据安全，第一反应是“加密”。

但真实场景里，数据安全远不止加密，还包括：

- 谁能看到数据
- 谁能修改数据
- 数据怎么传输
- 数据怎么存储
- 日志里会不会泄露
- 出问题后能不能追踪

所以数据安全不是一个点，而是一整条链路。

## 二、数据安全可以拆成哪几层

### 1. 传输安全

数据在网络上传输时，怎么避免被窃听或篡改。

最典型手段就是：

- HTTPS / TLS

### 2. 存储安全

数据落库、落盘后，怎么避免泄露和误用。

例如：

- 密码哈希
- 敏感字段加密
- 访问权限隔离

### 3. 访问控制

谁能查、谁能改、谁能导出。

这部分通常依赖：

- 认证
- 授权
- 审计

### 4. 输出安全

系统返回给前端、日志、报表、导出文件时，是否把不该暴露的信息带出去了。

这也是很多系统最容易忽视的一层。

## 三、最常见的敏感数据有哪些

- 密码
- 手机号
- 身份证号
- 邮箱
- 银行卡号
- 地址
- Access Token / Refresh Token
- API Key / Secret
- 支付密钥

一个很实用的习惯是：

**先在系统里明确什么算敏感数据。**

如果连这一步都没做，后面很难保护。

## 四、密码为什么必须哈希，不能“可逆加密”

密码存储最基本的原则：

**服务端不应该能轻易还原用户原始密码。**

所以密码通常不做“可逆解密”，而是做哈希。

原因很简单：

- 就算数据库泄露，也尽量别直接暴露原密码

这里要区分三件事：

- 密码存储：哈希
- 数据传输：HTTPS
- 部分敏感业务字段：必要时加密

## 五、哪些数据适合加密

常见适合加密的有：

- 身份证号
- 银行卡号
- 第三方密钥
- 特殊业务敏感字段

但不是所有字段都适合一股脑加密。

因为加密后会带来：

- 查询困难
- 索引受限
- 运维和密钥管理复杂

所以正确思路是：

**按敏感等级和使用场景决定。**

## 六、数据脱敏是在解决什么问题

脱敏不是保护原始存储，而是保护“展示和流转过程”。

例如：

- 管理后台展示手机号时只显示中间星号
- 日志里不打印完整 token
- 导出报表时隐藏部分身份证号

常见脱敏示例：

- 手机号：`138****0000`
- 身份证：`310***********1234`
- 邮箱：`a***@gmail.com`

## 七、日志为什么也是数据安全高风险区

很多系统不是数据库先泄露，而是日志先泄露。

常见问题：

- 把完整 token 打进日志
- 把用户隐私字段原样打印
- 把 SQL 入参全量打印
- 错误堆栈里暴露内部路径和密钥

所以日志也要做治理：

- 敏感字段掩码
- 错误信息分级
- 生产环境避免打印过细数据

## 八、后端项目里最容易忽略的几个点

### 1. 测试环境比生产更松，但也有真实数据

很多事故发生在测试、预发、导出环境。

### 2. 对象存储链接泄露

文件权限、签名 URL、公开桶配置都要小心。

### 3. 管理后台权限过粗

不是“是管理员”就应该能看一切。

### 4. 数据导出功能没做审计

导出往往是敏感数据外流的高风险操作。

## 九、最常见的安全手段分别在解决什么

| 手段 | 主要作用 |
|---|---|
| HTTPS | 保护传输链路 |
| 密码哈希 | 防止密码明文泄露 |
| 字段加密 | 保护高敏感字段 |
| RBAC / ABAC | 控制谁能访问 |
| 数据脱敏 | 控制展示和输出 |
| 审计日志 | 事后追踪责任 |
| 密钥轮换 | 降低密钥长期暴露风险 |
| 备份加密 | 防止备份文件泄露 |

## 十、一个中小后端系统的最小数据安全清单

1. 全站 HTTPS
2. 密码哈希存储
3. 敏感配置放环境变量或密钥管理系统
4. 后端做真实权限校验
5. 管理后台关键页面做脱敏展示
6. 导出、删除、权限变更留审计日志
7. 日志里屏蔽 token、密码、密钥、证件号

这 7 条做到了，已经能挡住大量低级事故。

## 十一、初学者最容易有的错误认知

### 1. 只要上了 HTTPS 就算安全

不是。HTTPS 只解决传输问题。

### 2. 只要登录了就算安全

不是。认证之后还要做授权。

### 3. 数据库存内网就安全

不是。很多泄露来自误操作、日志、导出和权限过宽。

### 4. 脱敏和加密是一个东西

不是。加密保护原始数据，脱敏保护展示和输出。

## 这篇最重要的结论

数据安全不是“加一层加密”就结束了，而是从传输、存储、访问、日志、导出到审计的全链路治理问题。
