# 系统设计

这一组文档面向已经会写接口、会用数据库和缓存，但还不太会系统化回答系统设计问题的开发者。

写法参考两条线：

- `JavaGuide` 的系统设计栏目组织方式
- 你当前项目里系统设计文档偏“可直接面试展开”的风格

目标不是把你训练成背八股的人，而是让你能把一个系统设计题讲清楚：

- 需求是什么
- 约束是什么
- 核心链路怎么走
- 数据怎么存
- 瓶颈在哪里
- 怎么扩展、兜底和排障

## 推荐顺序

1. 先看场景题模板，知道答题骨架。
2. 再看基础知识速通，把常见术语放回整体地图里。
3. 然后补认证授权和数据安全，避免系统设计只会讲吞吐和缓存，却不会讲边界保护。
