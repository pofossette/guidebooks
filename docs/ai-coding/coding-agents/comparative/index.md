# 横向比较

这里集中放 `Claude Code`、`OpenCode`、`Codex` 三套系统的横向对照，只负责比较，不负责主叙事。

建议按这个顺序读：

1. 先看 [关键差异与设计选择](./key-differences-and-design-choices.md)，用一张总表把三家的系统主干、任务模型和 control plane 差异压实。
2. 再看 [自建 Agent 时该抄什么、不该抄什么](./what-to-copy-when-building-your-own-agent.md)，把比较结果转成工程决策。

本分区只回答两类问题：

- 三家为什么不是同一种架构
- 哪些设计值得借鉴，哪些不要照搬

如果你现在只是想建立目录感，先看 [阅读地图](../overview-and-reading-map.md)。
