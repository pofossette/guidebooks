# 证据索引

这里集中放本专题的证据入口，只负责支撑后续判断，不重复论证。

建议按这个顺序用：

1. 先看 [统一证据页与源码索引](../source-evidence-and-code-index.md)，按设计问题或按系统快速定位源码与外部资料。
2. 再看 [外部资料与公开讨论索引](./external-references-and-public-discussions.md)，按主题查官方文档、公开 issue/discussion 与经验资料。

本区统一使用四类证据：

- 本地源码
- 官方文档
- 公开 issue / discussion
- 推断

每个关键判断都应尽量回到这四类证据之一，而不是停在印象层。
