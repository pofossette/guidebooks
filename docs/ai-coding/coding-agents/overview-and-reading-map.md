# 阅读地图

按“先总览、再专题、后证据”的顺序组织阅读。

1. 先看 [AI 编码 Agent 机制总览](./index.md)，确认这组文档的主线和分区。
2. 再进入 [设计原则主线](./design-principles/index.md)，先把 `Claude Code`、`OpenCode`、`Codex` 的差异放到同一把尺子上。
3. 如果你需要横向收束，再看 [横向比较](./comparative/index.md)，先读 [关键差异与设计选择](./comparative/key-differences-and-design-choices.md)，再读 [自建 Agent 时该抄什么、不该抄什么](./comparative/what-to-copy-when-building-your-own-agent.md)。
4. 最后回到 [证据索引](./evidence/index.md)，先用 [统一证据页与源码索引](./source-evidence-and-code-index.md) 定位材料，再按 [外部资料与公开讨论索引](./evidence/external-references-and-public-discussions.md) 复核官方文档、公开讨论和经验资料。

这版重构的目标很简单：主线负责解释原则，比较页负责收束差异，证据页负责支撑判断。
